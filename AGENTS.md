# Portafolio de Kevin Garzón

- Trabajar únicamente en este repositorio. La carpeta de Ahead es una referencia de solo lectura: nunca editarla, borrar archivos, ejecutar sus scripts, publicar ni cambiar su Git.
- Contenido público verificable en `apps/portfolio/content/` y secciones semánticas en `apps/portfolio/src/sections/`.
- Tokens visuales en `libs/ui/styles/tokens.css`. Movimiento con soporte para `prefers-reduced-motion`.
- Ejecutar `npm run check` y `npm run build` antes de entregar cambios funcionales.
- No inventar resultados de negocio, autoría de fotografías, clientes ni tecnologías.
- No copiar credenciales, bases de datos, configuraciones de despliegue o identificadores de Ahead.
- Conservar el ID propio del portafolio en `.openai/hosting.json`. No utilizar los destinos de Ahead para publicar este sitio.
